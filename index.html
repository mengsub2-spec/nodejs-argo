Frequently Asked Questions

Everything you need to know about code ownership, migration, and runtime performance.

Do we own the generated source code?

Yes, 100%. Unlike legacy low-code platforms that hold your application hostage, HyperFlow continuously writes standard, readable TypeScript and Rust into your designated Git repository. If you ever leave, your code runs independently on any Node.js, Cloudflare, or Docker runtime.

Can I write custom business logic that isn't in your components?

Absolutely. Every node in HyperFlow can be converted to an editable code snippet. You can import any npm package, run custom WASM routines, or interface with legacy internal APIs without arbitrary sandboxing restrictions.

How does this integrate with our current CI/CD pipelines?

HyperFlow acts as a standard git collaborator. It opens pull requests, obeys your branch protection rules, triggers your existing GitHub Actions or GitLab runners, and verifies automated testing suites prior to edge deployment.

What is your platform availability and security certification?

HyperFlow is SOC2 Type II certified, ISO 27001 compliant, and GDPR-ready. Our edge execution fabric runs with 99.99% multi-region redundancy, featuring instantaneous failover between US, EU, and APAC zones.
